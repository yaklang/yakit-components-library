# 源码归属

公共图标的来源、素材、组件、脚本和测试都在本包。UI 组件通过本包使用公共图标，并在 UI 包中维护组件私有 SVG。

| 内容                       | 位置                   |
| -------------------------- | ---------------------- |
| 当前原稿和生成规则         | `config/icon-sources/` |
| 公共组件和生产 SVG         | `src/`                 |
| 导入、生成、检查与构建工具 | `scripts/`、`config/`  |
| 当前规则及组件功能测试     | `test/`                |
| 功能测试样本               | `test/fixtures/icons/` |

`#manifest`、`#raw`、`#placement` 是从同一来源即时计算的数据视图，不是另外维护的 JSON 文件。

旧截图、历史审核和迁移资料已从工作目录删除，需要时通过 `git log --all -- <路径>`、`git show <提交>:<路径>` 查阅。当前检查不依赖这些文件或历史环境信息。

`pnpm icons:verify-isolation` 在没有 UI 源码的临时目录验证图标包生成检查、构建和产物可用性，不重复运行全套功能测试。
